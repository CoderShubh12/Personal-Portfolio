# Shubham Rai Portfolio

A modern, dark-themed portfolio landing page built with React.

## 🚀 Quick Start

```bash
# 1. Navigate to project folder
cd shubham-rai-portfolio

# 2. Install dependencies
npm install

# 3. Start development server
npm start

# 4. Open http://localhost:3000
```

## 📦 Build for Production

```bash
npm run build
```

Deploy the `build/` folder to **Vercel**, **Netlify**, or **GitHub Pages**.

## 🎨 Features

- Animated gradient mesh hero with floating orbs
- Smooth scroll navigation
- Responsive design (mobile-friendly)
- Project cards with hover effects
- Timeline experience section
- Contact cards with hover animations
- Dark theme with teal accent

## 📝 Customize

- Update project links in `src/components/Projects.jsx`
- Update contact info in `src/components/Contact.jsx`
- Replace images with your own screenshots
- Adjust colors in `src/App.css` :root variables
